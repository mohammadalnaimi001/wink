# وينك كافيه — موقع كامل مع نظام حجز
### Wink Cafe — full website + reservation system

موقع ثنائي اللغة (عربي / إنجليزي) لمقهى **وينك كافيه** — شارع الأميرة هيا، الزرقاء —
مع نظام حجز طاولات كامل، قاعدة بيانات، ولوحة تحكم للإدارة.

**بيانات الكافيه المستخدمة:** ‏٠٧٩ ٥٨٠ ٥٢٤٩ · 432V+3WR شارع الأميرة هيا، الزرقاء ·
تقييم ٣٫٩ من ١٬٦٣٨ مراجعة · ٥–١٠ د.أ للشخص · يفتح ١٠ صباحاً.

---

## ١. شو في بالمشروع

| القسم | الوصف |
|---|---|
| **الموقع** | صفحة واحدة كاملة: هيرو، عننا، القائمة بالأسعار، الأرجيلة وبث المباريات، معرض صور، آراء الزبائن، الموقع والاتجاهات، فورم تواصل |
| **اللغتان** | عربي (RTL) وإنجليزي (LTR) مع زر تبديل — اللغة بتنحفظ للزائر |
| **نظام الحجز** | ٣ خطوات: الوقت والقسم → تفاصيل القعدة → بياناتك. بيتحقق من المقاعد المتاحة لحظياً |
| **وصول الحجز** | يتخزّن بقاعدة البيانات + زر واتساب برسالة جاهزة على `0797851479` + إيميل (اختياري) |
| **لوحة التحكم** | `/admin` — إحصائيات، كل الحجوزات، تغيير الحالة، حذف، بحث وفلترة، تصدير CSV، إدارة المباريات وأيام الإغلاق والرسائل |
| **متابعة الحجز** | الزبون بيقدر يشوف حجزه أو يلغيه برقم الحجز + آخر ٤ أرقام من موبايله |
| **إضافات** | ملف تقويم `.ics`، حالة مفتوح/مسكّر لحظية، بيانات SEO منظّمة (Schema.org) |

## ٢. التشغيل على جهازك

بدك **Node.js نسخة 18 أو أحدث**.

```bash
npm install
cp .env.example .env        # وبعدين عدّل كلمة المرور والإعدادات
npm start
```

بعدها افتح:

- الموقع: <http://localhost:3000>
- لوحة التحكم: <http://localhost:3000/admin>

**كلمة مرور لوحة التحكم الافتراضية:** `wink2026` — غيّرها من ملف `.env` قبل النشر.

---

## ٣. الإعدادات (`.env`)

```ini
PORT=3000
TZ=Asia/Amman
ADMIN_PASSWORD=غيّرها        # كلمة مرور لوحة التحكم
SESSION_SECRET=نص-عشوائي-طويل
SECURE_COOKIE=false          # خلّيها true لما يصير الموقع على HTTPS
```

لتوليد `SESSION_SECRET`:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### تفعيل إشعارات الإيميل (اختياري)

الموقع بيشتغل تمام بدونها — الحجوزات بتتخزّن وزر الواتساب بيشتغل. لتفعيل الإيميل عبّي:

```ini
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASS=app-password       # مع Gmail لازم "App Password" مش كلمة المرور العادية
ADMIN_EMAIL=bookings@winkcafe.jo
```

بعد التفعيل: كل حجز بيوصل إيميل للإدارة، والزبون بيوصله تأكيد إذا حط إيميله.

### حط صورك الحقيقية

الصور الحالية رسومات SVG مؤقتة في `public/img/`. لما يكون عندك صور حقيقية:

1. حطّها في `public/img/` بأسماء `latte.jpg`, `waffle.jpg`, `shisha.jpg`, `mojito.jpg`, `crepe.jpg`, `matches.jpg`, `interior.jpg`, `terrace.jpg`
2. في `public/index.html` بدّل `/img/latte.svg` بـ `/img/latte.jpg` (وهكذا لباقي الصور)

نصيحة: خلّي الصور مربّعة وأقل من 300KB للوحدة عشان يضل الموقع سريع.

## ٥. كيف بتشتغل لوحة التحكم

| التبويب | شو بتعمل فيه |
|---|---|

| **المباريات** | تضيف مباراة → بتظهر مباشرة بقسم "المباريات القادمة عندنا" على الموقع |
| **أيام الإغلاق** | تضيف تاريخ → بيختفي من خيارات الحجز تلقائياً |
| **الرسائل** | رسائل فورم التواصل، مع زر "تم" لتعليمها كمعالَجة |

## ٦. كيف بيشتغل نظام التوفّر

- كل حجز بيحجز مقاعده **ساعتين** (`SLOT_HOLD_MINUTES` في `server/config.js`)
- لكل قسم عدد مقاعد ثابت (`capacity`)؛ ما بينقبل حجز إذا المقاعد المتبقية أقل من عدد الأشخاص
- ما بينقبل حجز قبل أقل من **٤٥ دقيقة** من الوقت المطلوب، ولا لأبعد من **٦٠ يوم**
- أوقات بعد منتصف الليل (00:00 – 02:00) بتنحسب على ليلة اليوم المختار مش اليوم اللي بعده

كل هاي الأرقام بتتغير من `server/config.js`.

## ٧. النشر على سيرفر

المشروع Node عادي، بيشتغل على أي استضافة بتدعم Node: Railway، Render، Fly.io، DigitalOcean، VPS، أو استضافة أردنية بتدعم Node.

الخطوات العامة:

```bash
npm install --omit=dev
NODE_ENV=production node server/index.js
```

**مهم قبل النشر:**

1. غيّر `ADMIN_PASSWORD` و `SESSION_SECRET` في `.env`
2. خلّي `SECURE_COOKIE=true` إذا الموقع على HTTPS
3. خُذ نسخة احتياطية من `data/wink.db` بشكل دوري — كل الحجوزات فيه
4. استخدم `pm2` أو `systemd` عشان السيرفر يضل شغّال:
   ```bash
   npm i -g pm2 && pm2 start server/index.js --name wink && pm2 save
   ```

## ٩. مسارات الـ API

**عامة**

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `/api/config` | بيانات الكافيه والأقسام |
| `GET` | `/api/menu` | القائمة |
| `GET` | `/api/matches` | المباريات القادمة |
| `GET` | `/api/availability?date=YYYY-MM-DD` | المقاعد المتاحة لكل وقت ولكل قسم |
| `POST` | `/api/bookings` | إنشاء حجز |
| `GET` | `/api/bookings/:code?phone=1234` | استعلام عن حجز |
| `POST` | `/api/bookings/:code/cancel` | إلغاء حجز |
| `POST` | `/api/contact` | رسالة تواصل |

**للإدارة** (بتحتاج تسجيل دخول): `/api/admin/login`, `/api/admin/bookings`,
`/api/admin/stats`, `/api/admin/export.csv`, `/api/admin/matches`,
`/api/admin/blackouts`, `/api/admin/messages`

## ١٠. ⚠️ لازم تراجعه قبل النشر

بيانات الاسم والهاتف والعنوان والتقييم مأخوذة من صفحتكم على خرائط جوجل. الباقي محتوى
جاهز للتعبئة — راجع النقاط التالية:

| البند | الوضع الحالي | وين تعدّله |
|---|---|---|
| **وقت الإغلاق** | جوجل بتذكر وقت الافتتاح (١٠ ص) بس — حطّينا منتصف الليل مؤقتاً | `server/config.js` ← `closeHour` وكمان صف "يومياً" في `public/index.html` |
| **آراء الزبائن** | ٣ بطاقات فاضية جاهزة للتعبئة | انسخ ٣ مراجعات حقيقية من صفحتك على جوجل → `public/index.html` (قسم `rev-grid`) و `public/js/i18n.js` (`rev.1n`…`rev.3p`) |
| **توزيع النجوم** | تقديري، محسوب ليعطي معدل ٣٫٩ | خُذ الأرقام الحقيقية من Google Business Profile ← إحصاءات، وعدّلها في `public/index.html` (قسم `bars`) |
| **الأسعار** | تقديرية ضمن المدى المعلن (٥–١٠ د.أ) | `data/menu.json` |
| **أزرار "اطلب عبر طلبات"** | مفعّلة برابط عام | إذا الكافيه مش على طلبات: خلّي `talabatUrl: ''` في `server/config.js` والأزرار بتختفي لحالها. وإذا موجود، حط رابط صفحتك المباشر |
| **الأقسام والمقاعد** | ٤ أقسام (داخلي ٦٠ · تراس ٤٥ · ركن مباريات ٤٠ · جلسة خاصة ٢٤) | `server/config.js` ← `areas` — احذف أو عدّل حسب الموجود فعلاً عندك |
| **الصور** | رسومات SVG مؤقتة | `public/img/` — راجع القسم ٤ فوق |
| **أرجيلة / بث مباريات** | أقسام كاملة موجودة بالموقع | إذا مش متوفرة عندك، احذف القسم من `public/index.html` أو خفّض `capacity` للأقسام المعنية |

**العطل الرسمية:** ساعات العمل بتتأثر بأيام زي المولد النبوي — استخدم تبويب
**أيام الإغلاق** في لوحة التحكم لتعطيل الحجز بهاي الأيام.
